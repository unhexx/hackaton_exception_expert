## Зазор, который двигает оценку

1. Шаблоны теста — заглушки одного каркаса на все пары. Критерий 25% (дискриминативность, экспертная оценка) падает с первого экрана.
2. Выдача фильтрует категорию, ранг — балл и ФСП, `list_reason` повторяет фильтр. Критерий 35% просит ранг по потребности и объяснимость.
3. Приглашение требует вручную ввести номер профиля, которого нет на карточке. 10% UI + живой проход 35%.
4. Q9 без URL. «Крайне желательно» для экспертизы 12–18.10. Абзац ATS в записке звучит как отказ, не концепция.
5. FSP-8 не открыт → из 7% почти ноль, кроме текста.
