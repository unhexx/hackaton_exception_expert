# Открытые вопросы

Писать модератору `@elizaveta_lct` и экспертам ФСП. Пока ответа нет, действует решение в колонке «пока так». Менять «пока так» может product, с записью ответа в этот файл. Разработчик не подменяет ответ догадкой в коде.

| ID | Вопрос | Пока так |
|----|--------|----------|
| Q1 | Агрегатор собирает вакансии с внешних площадок или вакансия рождается как предложение работодателя? | Вакансия — часть предложения. Внешний парсинг не делаем |
| Q2 | Зарплата: вилка, одна сумма, валюта, «по договорённости»? | Обязательная вилка в RUB. «По договорённости» не принимается |
| Q3 | «Механизм тестирования» — прогон качества матчинга или испытание соискателя? | Прогон качества на золотом наборе. Экзамен не делаем |
| Q4 | Какие поля достижений можно показать работодателю и нужно ли отдельное согласие? | Показ только открытого профиля. Сырые ФИО в репозиторий не кладём |
| Q5 | Соискатель без участия в ФСП допускается? | Да, категория «без подтверждения», визуально отдельно |
| Q6 | Идентификация участника в API: id федерации, почта, номер спортсмена? | В моке стабильный `external_id`. Связка с боевым id — в адаптере |
| Q7 | Командный результат хакатона записывается на каждого участника или на команду? | На каждого участника, с `role_in_team`. Командную карточку не делаем |
| Q8 | Брендбук обязателен к пикселю на экспертизе 12.10 или достаточно аккуратного UI до приезда макетов? | Нейтральная вёрстка со слотом токенов. После макетов — design |
| Q9 | Где должен быть развёрнут демо-стенд к 11.10 и кто даёт домен? | Инструкция на локальный и один публичный URL. Хост выбирает product до 04.10 |
| Q10 | Нужна ли модерация работодателя (юрлицо, ИНН) в прототипе? | Регистрация работодателя без проверки юрлица. Пометка «не проверен» на карточке |
