# План окна разработки

Календарь заказчика: [00-postanovka.md](00-postanovka.md). Разработка 05–11.10.2026, стоп-код 11.10.2026 в 23:59 МСК. До старта команда не дописывает продукт, а держит контракт мока и ответы на вопросы. В окно разработки не тащить задачи шаблона Agentix.

Один срез — один демонстрационный исход. Владелец указан компетенцией из [roles/CONTRACT.md](roles/CONTRACT.md).

Веса жюри и состав сдачи не копировать: они в [01-requirements.md](01-requirements.md). Срез, которого нет в приёмке MVP, в это окно не открывать. Свои вакансии, отклик и регулярные задачи — как раз такой хвост.

| ID | Срез | Готово, когда | Владелец |
|----|------|---------------|----------|
| FSP-1 | Каркас сервиса, два кабинета, почта | Соискатель и работодатель входят в разные оболочки. Адрес подтверждается кодом на стенде | frontend, backend |
| FSP-2 | Мок ФСП и карточка достижений | Профиль показывает дисциплину, роль на старте, результат и разряд из мока. Пустая история не ломает кабинет | backend |
| FSP-3 | Категория v1 | После опроса есть `category_id` из специализации и грейда, `rule_version` и объяснение. Прогон печатает отчёт | matching, backend |
| FSP-7 | Тест грейда | Шаблон выбирается не один на всех. Итог подтверждает грейд или предлагает соседний. Сам грейд не понижает. Повтор стабилен | matching |
| FSP-4 | Разбор резюме | Форма и текст PDF заполняют поля профиля с `source=resume`, без метки ФСП. Кабинет отдаёт стандартный PDF | matching |
| FSP-5 | Приглашение | Работодатель из категории шлёт текст, вилку RUB и компанию. Соискатель принимает. Контакт виден только после `accepted` | backend, frontend |
| FSP-6 | Стенд и документы | Инструкция запуска, OpenAPI, демо-скрипт, абзац про будущий реестр ФСП, токены бренда из требований | product, backend |

Порядок: FSP-1 и FSP-2 можно параллельно. FSP-3 после полей профиля из FSP-1. FSP-7 после FSP-3, на своих файлах. FSP-4 параллельно FSP-3. FSP-5 после FSP-1 и FSP-3. FSP-6 в последний день окна, 11.10. Токены бренда не блокируют FSP-1: до FSP-6 допустима нейтральная вёрстка с теми же именами переменных.
